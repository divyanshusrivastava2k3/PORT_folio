# Divyanshu Srivastava (Billboard Edition)

Single-file showcase site (`index.html`) in a **brutalist billboard** design: Archivo Black grotesque typography, full-viewport scroll-snap panels, outlined display type, inverted marquees, terminal-style live sentiment demo. Colors: `#590907` (oxblood field) · `#E8D2B5` (sand type) · `#A5A79B` (sage accents). No dependencies, no build step.

## Run locally
Open `index.html` in a browser — or:

```
npx serve .
```

## Deploy (GitHub Pages)
1. Push this folder's `index.html` to a repo root.
2. Repo → Settings → Pages → Source: `main` branch, `/ (root)`.
